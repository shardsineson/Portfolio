# Sadé Ineson — Portfolio website

A lightweight, responsive static portfolio for GitHub Pages. No build step, paid platform, tracking, or API key is required.

## Publish to GitHub Pages

1. Make a free GitHub account if you don't have one.
2. Click **New repository** and name it `portfolio`. Set visibility to **Public** (GitHub Pages on the Free plan requires a public repo).
3. On the repository page choose **Add file → Upload files**.
4. **Unzip the downloaded package first**, and upload `index.html`, `styles.css`, `script.js`, and the `assets` folder and its files. `index.html` must be at the repository root, not inside an extra `sade-portfolio` folder.
5. Commit the changes.
6. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Choose branch `main` and folder `/(root)`; save.
7. Your site will appear at `https://YOUR-USERNAME.github.io/portfolio/` after GitHub finishes publishing.

## Update later

- Edit text in `index.html` directly on GitHub, or ask ChatGPT to modify it and upload the replacement file.
- Edit the look in `styles.css` and filtering in `script.js`.
- Replace `assets/Sade-Ineson-CV.pdf` with an updated PDF **with the same filename** so the download link keeps working.
- You can test locally by opening `index.html` in a browser. Filters and links work without a server.

## Before sharing with employers

- Open and verify the LinkedIn link in the header/contact section, and the email address.
- Verify that the downloadable CV is your approved latest version.
- Confirm all career claims, percentages and policy/contract authorship wording are factually correct and appropriate to share publicly.
- This is a public portfolio. Avoid putting confidential company data or personal employee information into it.

## Notes

Fonts load from Google Fonts when online and use local system fallbacks if unavailable. There is no analytics or visitor tracking. Case-study filters work in the browser and do not send any data anywhere.
